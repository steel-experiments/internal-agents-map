# Preserved source material

This directory contains immutable evidence snapshots used by the Internal Agents Map. See the
[source-preservation policy](../docs/source-preservation.md) for capture, validation, retention,
and takedown rules.

Each source bundle lives at `archive/sources/<source-id>/` and contains a required
`metadata.json`, required `content.md`, and an optional `page.pdf`.

The archived material remains the property of its original publisher or author. It is not
licensed under the repository's MIT or CC BY-SA licenses. The material is retained for citation,
verification, research, and historical reference with attribution to its original URL.
