AI coding tools solved the generation problem. Code ships faster, more services get built, output goes up.

But something else happened. It took new engineers months to ramp up. AI agents made fast, confident decisions that were technically correct and operationally wrong — because they didn't know what they were actually working inside.

The knowledge that would fix this wasn't missing. It was in Slack threads nobody could find, in the heads of the three people who built that service in 2021.

That's not a documentation problem. It's a retrieval problem. And READMEs, Confluence pages, and architecture diagrams don't solve it — they just go stale while the real work keeps moving.

Xirp is different. It's an agentic development environment that understands your code. Connect it to Portal, and it knows your services, ownership, dependencies, and architectural decisions — all of it, in every session. Your agents don't guess. They know.

Agent

### The agentic development environment with institutional memory.

Other agents see the file you're working in. Xirp sees the system it's part of: who owns the upstream service, what depends on it, why it was built this way. Every session starts grounded, and every session makes the next one smarter.

![The Xirp desktop app showing a coding session grounded in real project context](https://xirp.spotify.com/_next/static/media/feature-agent.1wd_g1-gw11st.webp)

Documentation

### Living documentation, built automatically.

Every coding session generates real knowledge. Xirp captures it, turns it into documentation that stays current, and feeds it back into future sessions so every agent and engineer starts smarter. No more asking engineers to stop and write docs. It happens as the work happens.

![Xirp documentation that stays current, generated automatically from coding sessions](https://xirp.spotify.com/_next/static/media/feature-documentation.3jiawz-5nywbd.webp)

Flexibility

### Works with Claude, Gemini, Codex. Knows your org, not theirs.

Xirp is a harness for the model you prefer. Switch between Claude, Gemini and Codex without losing context. Run sessions locally or remotely. Stay vendor-independent while the context layer compounds with every session.
