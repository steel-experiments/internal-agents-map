## Findings considered and rejected

  provenance and would make generated catalog output depend on transient network state.
  Render the original and preserved copy together instead.
- GitHub Actions artifacts as permanent storage: rejected because Actions artifacts expire.
- Raw HTML snapshots: rejected for the first version because scripts, remote assets, and
  dynamic dependencies make them unsafe and unreliable as durable evidence.
- A PDF for every source: rejected because many sources are repositories, videos, or social
  pages for which PDF is misleading, and bulk PDFs would grow Git history quickly. PDF is an
  opt-in artifact when layout or visual evidence matters.
- Waiting for the scheduled checker before capturing: rejected because a confirmed 404/410
  may already be unrecoverable by then.
